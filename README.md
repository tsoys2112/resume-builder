# Конструктор резюме и сайта‑портфолио (Gemini)

Заполняете анкету → Gemini пишет описание, сильные стороны и достижения → готовое резюме (PDF) и мини‑сайт портфолио (HTML).

## Возможности
- Анкета: фото, имя, должность, дата рождения (возраст считается сам), город, контакты, опыт, образование, навыки, языки
- ИИ Gemini: заголовок профиля, описание, 4 сильные стороны, опыт в виде достижений, группы навыков, текст для сайта. Язык: русский / английский / узбекский, 3 тона
- Текст ИИ можно поправить вручную
- 4 шаблона резюме: Классика, Модерн, Минимал, Креатив + 8 цветов и свой цвет
- Скачивание PDF (A4) и печать; сайт‑портфолио скачивается одним .html файлом
- Адаптив: компьютер, планшет, телефон; светлая/тёмная тема интерфейса
- Данные автоматически сохраняются в браузере

## Структура
```
index.html          — интерфейс
css/style.css       — стили приложения
css/resume.css      — стили 4 шаблонов резюме
js/templates.js     — шаблоны резюме и генератор сайта
js/prompt.js        — промпт и JSON‑схема для Gemini (общий для сервера и браузера)
js/app.js           — логика
api/generate.js     — серверная функция Vercel: ключ Gemini хранится на сервере
```

## Деплой на Vercel (GitHub → Vercel)
1. Получите ключ: https://aistudio.google.com/apikey
2. Залейте папку в новый репозиторий GitHub.
3. Vercel → Add New → Project → выберите репозиторий. Framework Preset: **Other**, сборка не нужна.
4. Settings → Environment Variables:
   - `GEMINI_API_KEY` = ваш ключ
   - (необязательно) `GEMINI_MODEL` = например `gemini-2.5-flash`. По умолчанию `gemini-flash-latest` — всегда свежая Flash‑модель.
5. Deploy. Готово.

## Локальный запуск без сервера
Откройте `index.html` (или `npx serve .`), нажмите ⚙ и вставьте ключ Gemini — запросы пойдут напрямую из браузера. Для публичного сайта так не делайте: используйте Vercel‑вариант, чтобы ключ не был виден.
